# Google Apps Script

Google ドライブ・スプレッドシート・ドキュメントの処理を自動にするスクリプトです。Google Apps Script のエディタに貼って、各ファイルの冒頭の設定項目を埋めて使います。

### Receipt_Summary

PDF形式の領収書を自動で解析し、内容をスプレッドシートに整理するGoogle Apps Scriptです。

- **機能**:
  - 指定フォルダ内のPDF領収書をGemini APIで解析
  - 研究費の使途、請求日、金額などの情報を抽出
  - 月別にスプレッドシートに整理
  - 処理済みのPDFファイルを整理

- **使用方法**:
  - Google Apps Scriptとして設定
  - Gemini APIキーと処理対象フォルダの設定が必要

### 論文データ抽出（gas-data-extraction）

Google ドライブのフォルダにある論文ファイル（PDF・PNG）から、Gemini API でデータを抽出し、スプレッドシートにまとめるスクリプトです。

- **出力**: 論文のファイル名、著者と年の表記、ファイルの URL、抽出したデータの入ったスプレッドシート
- **使用方法**:
  - Gemini の API キーと、論文を置いたフォルダの ID の設定が必要

### レポートへの自動フィードバック（DocFeedbackBatch）

指定した Google ドライブのフォルダにある Google ドキュメント（レポート）を見張り、新しく作られた・更新された文書に、Claude によるフィードバックをコメントで付けるスクリプトです。処理の状況は、自動で作られるスプレッドシートに記録されます。

- **使用方法**:
  - [レポートフィードバックGAS.js](%E3%83%AC%E3%83%9D%E3%83%BC%E3%83%88%E3%83%95%E3%82%A3%E3%83%BC%E3%83%89%E3%83%90%E3%83%83%E3%82%AFGAS.js) を Google Apps Script に貼り、冒頭の設定項目を埋める
  - Claude の API キーが必要
