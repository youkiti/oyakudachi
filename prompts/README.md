# プロンプト

AI に貼って使うプロンプトを、研究の段階ごとに分けています。

| フォルダ | 段階 |
|---------|------|
| [1-question/](1-question/) | 問いを立てる |
| [2-search/](2-search/) | 文献を探す |
| [3-appraisal/](3-appraisal/) | 結果を読む |
| [4-writing/](4-writing/) | 書く・投稿する |
| [5-teaching/](5-teaching/) | 教える・会を開く |

「無料版で可」のプロンプトは、ページの「プロンプト本文」の枠の右上にあるコピーボタンで本文をコピーし、Gemini（https://gemini.google.com/）か ChatGPT（https://chatgpt.com/）の新しいチャットに貼って送信すれば始まります。AI が示した文献や研究者は、リンクを開いて実在を確かめてから使ってください。
