# 5. 教える・会を開く

### ワークショップ開催の計画支援

ワークショップや研修会、セミナーの開催に当たって考えるべきことを、漏れなく整理するための対話プロンプトです。AI がワークショップ運営の経験者として質問し、答えに応じて案や改善点を示します。

- **機能**:
  - テーマ・目的、日時・会場、参加者、プログラム、講師、運営体制、機材、準備、当日の案内、評価、フォローアップ、費用の12項目を、一度に最大3つずつ質問
  - 行動目標（参加者が終わった後にできるようになること）と、その評価・追跡の方法への助言
  - 対面・オンライン・ハイブリッドに応じたプログラム構成や時間配分、準備のチェックリスト、当日の進行表の作成支援
  - 決まったことを1つの一覧にまとめて出力（未定の項目は「未定」と表示）

- **使用方法**:
  - [workshop planning prompt.md](workshop%20planning%20prompt.md) のプロンプト本文をコピーし、Gemini や ChatGPT（無料版で可）の新しいチャットに貼って送信する
  - API キーやアカウントの有料登録は不要
  - 最初は「医療者向けの論文執筆セミナーを行いたい」のように一言で答えれば、AI が順に聞いてくる
