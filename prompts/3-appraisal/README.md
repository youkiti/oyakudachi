# 3. 結果を読む

### 統計的有意と臨床的意義の読み解き（bottom line message builder）

研究結果を、p 値だけでなく臨床的な意味から判断するためのプロンプトです。AI が、統計的有意と臨床的意義の違いを踏まえて結果を読み解く手助けをします。

- **機能**:
  - 臨床領域、アウトカム指標、臨床的な閾値（MCID）、効果量と信頼区間などのうち、足りない情報を日本語で尋ねる
  - 信頼区間と臨床的な閾値の関係、絶対効果、患者への影響、費用と害を踏まえて結果を評価する

- **使用方法**:
  - [bottom line message builder.md](bottom%20line%20message%20builder.md) のプロンプトをコピーし、AI のチャットに貼って使う
